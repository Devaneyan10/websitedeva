# Devaneyan Muniandy — Personal Portfolio

A recruiter-friendly personal portfolio inspired by the visual language of the reference portfolio supplied by the user: dark navy/black background, purple glow accents, rounded cards, timeline experience, project showcase, services and a large contact section.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

For a production check:

```bash
npm run build
npm start
```

## Included

- Purple / indigo dark visual design inspired by the supplied reference
- Hero section using Devaneyan's supplied profile photo (`public/profile.jpg`)
- About, Skills, Experience, Projects, Services, Education, Recognition and Contact sections
- Filterable project cards
- Clickable project case studies
- Responsive desktop, tablet and mobile layouts
- Recruiter-focused measurable outcomes

## Customize

Main content: `app/page.tsx`

Visual styling: `app/globals.css`

Profile image: `public/profile.jpg`

Replace the profile image with another portrait using the same filename if needed.
